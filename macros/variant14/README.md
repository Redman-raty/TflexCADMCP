# Макросы варианта № 14

Исходники рассчитаны на редактор C#-макросов T-FLEX CAD 18. Откройте рабочую копию документа, выберите **Инструменты → Редактор макросов**, добавьте по модулю на нужный файл и скомпилируйте проект через **Ctrl+F7**. Команды появляются в панели **Макросы**. Запускайте только тот этап, который нужен открытому документу.

| Файл | Команда и назначение |
| --- | --- |
| [Variant14.cs](Variant14.cs) | `BuildBase` строит торцевой профиль и выталкивание корпуса в пустом 3D-документе |
| [CenterBase.cs](CenterBase.cs) | `CenterBase` задаёт два отступа по 70 мм операции корпуса, созданной предыдущим макросом |
| [CheckDimensions.cs](CheckDimensions.cs) | `CheckDimensions` записывает габариты 3D-операций в метрах в `%TEMP%\TFlex-Variant14-dimensions.txt` |
| [PrepareHalfSection.cs](PrepareHalfSection.cs) | `PrepareHalfSection` создаёт 3D-узел (0, 0, 80) мм для привязки команды «Местный разрез» к плоскости Y = 0 |
| [AnnotateSheet.cs](AnnotateSheet.cs) | `AnnotateSheet` добавляет оси, линейные размеры, выноски и заголовок на подготовленный лист |

Для `AnnotateSheet` нужен лист «Чертёж» формата А3 в масштабе 1:1 с проекциями «Проекция — Главный вид», «Проекция — Вид слева» и «Проекция — Вид сверху» в компоновке варианта № 14. Используется стандартный отступ границы проекции 7 мм. Постройте правую половину разреза командой «Местный разрез» и при необходимости сделайте её прямую границу вспомогательной линией. Размеры привязаны к 2D-узлам, поэтому после перемещения видов или изменения модели их следует проверить.

Бобышка, отверстия, резьбы, проекции и сам разрез строятся отдельно. В готовом локальном GRS сохранены эти операции и история построения.
